
# AI卷王们，从窄路走向宽阔？



**向外扩张技能的广度，向内加固基础的深度。**



1



人工智能冲击职场的两年，打工人群体面对AI工具，到底怎么用无非就三种态度：



可用可不用，免费的随便试试看。



嘴上反复强调AI转型，实际上全国各地跑资源，连模型和智能体都分不清。



**当下真正该关注的角色，是专注用好AI的卷王们。**



在每一轮科技变革的趋势中，都会奖励方向正确的工匠精神，前提是需要走过孤独的旷野，行完当行的路才能得到结果。



比如信息化浪潮中，提前完成产品系统建设。



发展到数字化转型阶段，轻松的实现业务和组织升级。



步入智能化进程里，在信息化和数字化的基础上，才具备从容应对的时间和空间，很多企业想借助AI横跨三步，幻觉比三流的模型还严重。



**企业的生存环境如此，打工人所面对的窄路亦如此。**



公司的产品研发团队，向来是卷王最多的部门，有人专注在开发AI应用，有人沉浸在用好AI工具。



相同点不在AI本身，目的是拉长手里的绳子。



假设借助AI能做很多事，前提是能熟练的使用它，需要知道自己想要什么结果，还要懂得让结果发挥价值，生产到销售的复杂链路，能驾驭的人寥寥无几。



**参与AI浪潮的人很多，坚持到底的人很少。**



2



AI在职场扩大辐射范围，真正大节奏开始于今年。



观察团队AI卷王半年之久，他的行为操作非常坚定，所有大模型可以做的事，全部指挥模型去完成，个人精力放在提升判断上。



**他能做的事越来越多，团队依赖他越来越明显。**



个人专业技能横向扩大，必然应对更多复杂任务，会对自身形成反向拉扯，如果缺乏基础能力的深度，容易疲于忙碌没有方向。



**什么样的基础能力，能承接定时的周期变化？**



团队消耗Token最多的AI用户，电脑桌面永远打开Claude Code终端，搭配原生的大模型，当成真正的助手调用。



提升需求理解的视野高度，完成任务的拆分和管理，当AI的输出超越能力边界时，还要设计判断和验收机制。



**挤出来的时间，自然有更好的去处。**



产品是权衡利弊的选择，要预备更多的时间空间，协调多方的争吵和利益。



纯粹的执行有贬值的趋势，复杂中的判断和选择愈发升值，AI够不到的地方越来越少，标准化的流程都能被替代，想自己不被轻松取代，人要主动预备稀缺特质。



**当趁着还有路可走，给未来创建新分支。**



互联网寒冬的这几年，就算没挨过裁员的刀，也承担降本增效的压力，想彻底逃脱这种处境，就要降低对稳定的依赖程度。



**如果变化像贼一样来到，措手不及被偷家是常态。**



所以持续提高觉察能力，看清关键问题和潜在风险，锻炼面对复杂状况的心态，未必要同时解决很多事，但该有信心应对悬而未决。



**互联网中隐而未现的风险，简直是自带的基因。**



不过组织中的卷王选手，借助对AI游刃有余的驾驭，不断张开自己的影响范围，让公司发现AI转型的价值，形成个体与企业的深度互选。



3



**有些事需要三思而后行，有些答案要在路上寻找。**



用心揣摩公司厉害的角色，发现这些人的基本特征：自身的专业能力不差，向核心业务与客户靠近，并且为目标持续行动。



总觉得上辈人错过许多机遇，轮到我们这辈依然如此。



九零后这群中间带，在移动互联网的尾巴摇摆，迷茫中参与数字化的搭建，眼睁睁的看着人工智能崛起。



两辈人的经历，既相似又不同。



**站在万物的变化里，因为厌烦不敢应对；看着迎面走来的机会，由于胆怯擦肩而过；面对未来的未知数，心里找不到方向感。**



生活的一粒黑沙，可以精准的定位每个人。



赢有赢的输法，输的态度好也是赢，努力但不要用力，维持信心的松弛感。



在人工智能的背景里，打工人的路有多窄，每个人心里都清楚，AI的技能多宽阔，用户和创造者都不知道。



**因为深度不确定，所以想寻找平静安稳。**



对互联网民工而言，无法分析哪个职位安全，只能把目光收回自己身上。



借助AI搭建自己的组合能力，在公司的业务中反复练习，从多维度分析形成综合判断，并且框架不与场景深度绑定，具备随时迁移的灵活性。



**客观上总是没准备好，主观里要坦然无惧的选择。**
