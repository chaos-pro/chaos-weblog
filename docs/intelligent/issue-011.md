# AI生产力：从效率到工作流重构



**人和人之间，没有幻觉是最大的共识。**



**1**



2023年人工智能彻底爆发，很多企业和个人在焦虑中观望，当时AI的能力尚不稳定，但在确定性的趋势中，互联网企业的一惯态度：

**参与或凑热闹，都必须要趁早。**

2024年很多公司开始尝试AI能力，不过还处在单点的形式，比如设计师验证视觉创意，产品和开发搭建业务流程，企业整理和搭建知识库。

虽然实践遇到各种奇葩问题，但用起来可以缓解焦虑，并且满足对新事物的猎奇心。

2025年在企业的工作流中，AI工具的使用彻底铺开，主要集中在产品研发领域，社交媒体上发布各种创意玩法，去年几款模型的惊艳能力，几乎霸占全年的流量效应。

**为什么又是编程领域？因为AI让产品的验证成本趋近于零。**

2026年AI的话题热度在降温，但工作场景中却持续升温，OpenClaw小龙虾到Codex产品，AI应用不想拘泥于纯粹的编程，开始连接组织协作的上下游。

**从单点效率的提升，转向重构工作流的综合领域。**



**2**



年初养龙虾火遍全球，但很多用户在尝试后选择放弃，并不是这款智能体不好用，而是找不到有价值的场景，只能白白消耗大量的Token，社媒的话题热度也断崖式降低。

**但企业真实的工作流中，OpenClaw们反而不断增加。**

在销售和运营岗中，经常要记录线索或想法创意。

有的人习惯临时发给聊天框，等忙完后再统一整理信息，现在直接发给OpenClaw智能体，由AI工具自动整理，甚至进行适当的完善，最终写入文档或者产品系统。

最热门的产品研发领域，AI工具更是加速进化，已经不是纯粹的编程方向。

Cowork和Codex极具代表性，从垂直领域向工作流进化，通过插件市场的持续扩展，AI IDE所能串联的场景，几乎可以覆盖在线流程。

三月份做过一款轻量产品，主要分析复杂流程的质量。

项目的需求很明确，在按年交付的业务中，需要从周期跟踪和监控质量，只要定义清楚指标和数据维度，产品自然没有开发难度。

唯一的麻烦点是：**三人不在同一个城市，所以要先对齐AI协作的共识：**

基于Codex管理项目，所有文件上传Git仓库，业务方定义关键的指标，Codex分析数据的支撑能力，产品在关键场景编程出效果图，最后由开发维护完整的工程。

每周需求完成后演示，项目发起方非常认可。

项目里重构人和AI的协作，人指挥AI完成需求标准化，信息在工作流不同节点传递和扩展，但始终在Codex内部处理，所以需求还原度非常高。

不过要强调一句关键：虽然AI和工作流相互融合，但核心节点都是专业人员负责，并且对齐AI使用和协作模式。

**管理者没有幻觉：一人一AI可以横推项目，才是效率和质量的前提。**



**3**



在人与人与AI协作的流程中，虽然直观感觉就是借AI增效，但细节处的变化值得反思和分析。

什么是对齐共识？从AI的视角分析项目。

由人来定义流程和规则，只是不同节点和需求，输入信息的边界有变化，AI针对各角色要求做输出，但信息传递过程的理解，交给AI自己设计规则，维持上下文处理的一致性。

**至于人和人之间，没有幻觉是最大的共识。**

**为什么可以提升效率？因为把复用做到最大化。**

企业级的项目和需求中，存在大量文档和已有工程，想要在此基础上分析需求，这一步费时费力效率低。

不同角色都需要理解业务，并且还容易出现偏差问题。

在AI工具中把输入当知识库，分析整理后再做标准化输出，同步相关成员的文档质量很高，等到项目完成阶段，所有文档皆可回溯。

**与其管理Prompt和Skill，聚焦在AI输出的结果上，更容易提升团队协作效率。**



**4**



社媒上有一个很火的话题：打工人的经验和技能，是否会被AI蒸馏和复制，站在人与AI协作的角度，这是必然发生的事情。

**很多专业领域的用户，在投喂AI语料教AI做事，所以它的进化速度非常快。**

**当然变化也是人的底色，质疑AI理解AI到使用AI，适应的过程还历历在目。**

最后聊聊经验和技能，打工人的核心竞争力。

当初学专业的笔记还在吗？相信大部分人都没保留，而能力在不断积累和更新，关注和思考的角度在变化，在AI蒸馏我们的同时。

也可以用AI的能力，去蒸馏一下魔幻的职场。
