# 圈外人焦虑AI吗？



**互联网和AI，是不是内循环？**

最近这段时间，两家大厂的AI产品，又一次被绑在社交媒体的首页，全网关注的话题，首页带来的流量与热搜差不多。

当前AI的能力和潜力，已经毋庸置疑。

但是从人工智能爆火出圈开始，这个行业任何的风吹草动，都会带来一场自媒体盛宴。

**影响的人群够大，关注的人自然够多。**

大模型厂商经过三年的发展，有的选择躺平摆烂，有的还在苦苦支棱，有的选择饱和式投流，有的选择安静做研发。

虽然姿势五花八门，但是挂热搜的方式出奇一致。

作为互联网行业的民工，不管你愿不愿意，这几年都会接收很多AI的信息，作为具有颠覆性的技术创新，毫无疑问是现在和未来的趋势。

但想从眼花缭乱的内容中，真正的看清现状也不容易。

AI行业的资讯信息，不知道从哪刮过来的风气，各种黑话术语盛行，比如："颠覆"，"震惊"，"爆火"，"掀翻"，"革命性产品"，"深夜沸腾"，"行业地震"，"见证历史"等等。

**所谓惊艳的提示词案例，可能只是反复执行中的灵光乍现。**

如果你稍微向算法表达过对AI的兴趣，那么这些反胃的词语，在社媒上三次刷新，至少可以看到两次，基于过往的营销和实测对比：

同一时段同类型账号，同样的推广话术，可能就是单纯的广告刷屏，靠着凭亿近人，想要吸引更多的用户尝试。

贴脸广告的产品也许不错，但是口碑更有性价比。

从三年的发展来看，引发全网认同的模型和产品，应该不会超过五个，回头看一看行业，靠着有口皆碑的效应出圈的寥寥无几。

**除了脑腐的营销黑话，另一大特色就是岗位躺枪。**

模型的绘图强一点设计师没了，模型的编程强一点开发者没了，模型的业务强一点产品没了，模型的自动化强一点运维没了，模型的质检强一点测试没了。

互联网行业的岗位，在模型迭代中很难安稳三天。

在这种叙事的逻辑中，AI哪方面能力突出，就等于圈外小白可以平替业内选手，不亚于脑回路上开黑洞，会用AI可以横竖的跨岗位，模型会的等于我也会？

**大模型真正助推的是：低成本地提升效率。**

用更少的时间完成更多的事，这是很多岗位被卷铺盖的一个因素，降本不一定增效，但是增效必然会降本，如果业务向上持续发展，对岗位的需求必然越来越多。

其实AI行业，真正颠覆的是三年的发展速度。

大模型从最初的玩具，到各行各业的效率工具，令人惊讶的是进步的速度，简直一天一个样，稍微不注意，就有种被时代甩在身后的幻觉。

**冷静的想一想，这算不算关心则乱？**

互联网行业的民工，被全球的热搜影响，人工智能行业的门槛更高，圈外人只能被动震惊，这两个行业天然契合。

**过去互联网\+，现在人工智能\+，组合起来绝佳。**

互联网是流量，大模型是产品，流量对于产品的描述，到底准不准确，可能两边都说不清楚，作为用户只能带着自己的需求去尝试。

任何出圈的模型，都有能力独特的一面。

从自己每天都用AI产品的实况来说，目前还没有哪款模型，能做到全方位的领先，等哪天真的有模型做到通用智能，可能这些词组到一起，也不足以描述AGI的震撼。

最后有个问题：圈外人关注和讨论AI，到底多不多？
