# 重新理解AI：从工具到可协作的助手



**动手的事在减少，动脑的事在增加。**



**1**



从AI正式出场算起，不过短短三年多时间，许多事都在喧嚣中悄悄变化。

翻看2023年的对话，无非就是和AI说句话，让它写写工作报告，分析具体的业务或数据，心底里还是把AI当玩具。

提问到验收到修改全程参与，才能得到一份可用的信息。

翻看2024年的对话，AI参与的流程开始增加，产品需求的设计到辅助研发，工作流中的文档和图片制作，AI工具的能力越来越强。

产品研发这个领域中，团队重心向主线聚拢，分支开始由AI代劳。

2025年不用翻什么记录，模型的王炸版本一个接一个，实践场景几乎覆盖整个工作流，任务执行的质量和效率，综合来说已经不输人工。

**部分激进的AI拥护者，已经开始转向指挥角色。**

2026年模型新版本还在进化，但已经很难给用户王炸感，当AI的能力达到及格线后，想法是为数不多的门槛。

社媒因此出现新趋势：劝退计算机专业。

过去十几年最能打的行业，被从业者调侃为不如去摆摊，大模型的编程能力，把开发的门槛铲到地平线，撞上存量竞争需求减少，供需失衡导致卷的离谱。

**模型作为核心的产品，基础形态依旧是对话框。**

但AI能力的深度和广度，却已经跨越好多个台阶，理解和推理，行动和生成，这几步搭建的能力组合，可以接管的任务愈发增多，在互联网领域内，更加考验个人的综合能力。

**人手操作的任务减少，人脑思考的事情在翻倍增加。**



**2**



互联网行业的民工，算实践AI最积极的一批人，在模型能力稍微可用的阶段，大部分的小企业和团队，就开始不断尝试。

**处在降本增效的阶段，被AI不遗余力的推一把。**

从自己真实的实践过程看，编写文档和业务分析，以及从AI挖掘创意，是2024年最普遍的用法。

工作流中的文档和周报，打工人最厌烦的事，最先被AI能力覆盖；业务分析开始借AI扩展完善，设计和绘图开始从AI找创意。

**互联网企业的工作流，半推半就的让AI挤进来。**

真正爆发是2025年的编程，从Claude模型到Cursor智能体，产品研发成本最高的岗位，开始被一步步的拉下来，模型厂商纷纷押注该领域。

很多人可能一头雾水，为什么又是计算机行业？

**互联网发展趋势不变的情况下，计算机和关联密切的编程，依旧是头部耐打的行业；对初创企业和个体来说，用编程实现产品0到1的成本，可以被极大程度的压缩。**

但面对头部超级应用，大模型迭代的降维打击，想完成1到100的历程也更艰难。

2026年不断进化的模型版本，却没有砸出全民参与的效应。

缺乏断层领先的垂直能力，很容易被深度付费用户抛弃，比如Claude模型的编程能力，ChatGPT模型的综合能力，DeepSeek模型极致的性价比。

Claude正从垂直领域横向扩展，ChatGPT开始从通用智能纵向深入，DeepSeek成本和能力平衡，正好切中用户的痛点。

**越来越多的AI能力够用，用户也会考虑降本增效。**

当垂直领域的需求被解决，必然会转向流程的升级优化，从这个角度去分析人工智能，不难理解Claude模型的进化节奏。

**编程智能体的再次扩展，就能接管产品研发更多流程。**

以Claude桌面端和Codex为例，只要底层的模型能力够强，就会被用户挖掘各种新玩法，已经算不上是纯粹的编程工具。

最近在做的轻量级项目，把文件工程维护在Git仓库，统一使用Codex进行管理，协调产品需求和开发节奏，质量和效率都有明显提升。

**流程设计和任务执行被重构，问题是效率提升后该怎么办？**



**3**



今年各厂商的模型能力，几乎都能跑到及格线外，比拼擅长领域的深度，以及综合能力的广度，会成为下阶段最惨烈的竞争。

**三年的信息流轰炸，似乎进入短暂的安静期。**

最初实践AI的互联网企业，工作流和工具都趋于稳定，如果业务回暖依旧会扩张，如果业务泥沙俱下，裁员和AI也不解决根本问题。

人工智能的深度进化，会扩展未来的想象空间。

从2023年回答一个问题，到2026年执行复杂的流程，底层基础能力的升级换代，对上层应用的高效驱动，同时又压缩人工介入的空间。

**大模型产品本身，更是排着队表演：**

前后不过两三年时间，起初OpenAI遥遥领先，没想到Anthropic弯道超车，随后Google打一场翻身仗，旁边的DeepDeek还可能砸场。

**用户却不乐意跟着转场，逐步稳定自己的AI团队。**

基于过往的实践经验，完成提示词和技能沉淀，开始学着合理的组合调度，探索降本增效的最佳策略，任由模型自己去内卷。

**AI真正登堂入室，到现在不过两年，再过三五年会如何，确实让人无法想象。**
