# 你在用AI，还是在围观AI？



最近这段时间刷社媒，越来越多的帖子在表达：对AI信息流已经厌烦，或者讨论反直觉的思考，AI的侧面话题越来越多。

自己不关注这个角度，但算法却把握得恰如其分。

人工智能在过去这段时间，全网参与的热点青黄不接，也许是去年的几款模型太惊艳，满足大部分用户的大多数需求。

**所以AI的饱和式热搜，用户已经开始免疫。**

普通AI话题的阅读量下降，既有内容的疲劳感，也存在流量本身的变化，处在这种窗口期，角度够倾斜才更可能出圈。

关注少的另一面：AI的安全性，人类是否被替代等；在热点缺乏的时候，频繁出优质的爆款长文。

**外行人读了不明觉厉，内行人读了沉默焦虑。**

作为AI产品的重度用户，偶尔也理性的思考一会：当下的人工智能真的如此吗？

首先理解一个现象：为什么AI内容遍地都是？



**第一条反直觉**：算法对行为数据的分析，可能比你更了解你自己，认知可能存在误区，但长期的行为很难说谎。

想看更多的知识科普，却在擦边和猎奇停留更久。

社交媒体中AI内容太多，可能你的实际行为，本身更关注这个方向，算法自然而然的调整推荐机制，会从你关注到猜你真喜好。

**个人主观行为说明白，再客观的分析内容趋势。**

AI内容天然具备流量优势，号称和全人类都相关，直接击中用户的猎奇心，各种安全问题和替代焦虑，持续的制造争议和冲突感。

在推荐的信息流中，各种离谱的标题党风格，更容易吃到流量效应。



**第二条反直觉**：社媒内容的推荐算法，会给AI用户形成信息茧房，在工作中每天用AI工具，也会搜索和关注最新动态，自然被推荐更多的话题。

如果使用的AI产品足够多，覆盖场景也算全面，自然清楚各类观点的合理性。

**实践才能出真知，简单道理的含金量很高。**

社媒叙事喜欢极端与戏剧性：比如AI超越人类后，程序员该何去何从，超级个体用AI轻创业等，其实真正的门槛始终存在，与是否使用AI的关系不大。

AI热点效应一茬接一茬，内容围绕流量持续套利。



**第三条反直觉**：AI用户的规模是否被高估，从ChatGPT到DeepSeek模型，用户破亿的速度刷新记录，但后续总会趋于平缓。

注册用户规模庞大，深度使用和付费人群，还是集中在垂直领域。

互联网公司与科研人群，最为紧跟人工智能的发展，讨论声最频繁的新媒体，也未必是真正的深度用户，人群特征明显偏向脑力劳动。

**频繁讨论AI的人，依旧是互联网活跃圈层。**

万字长文经常分析的话题：人类可能被AI替代的进程，普遍以深度用户为缩影，社媒讨论AI的热度，不等于使用的深度。

**用部分人群代表人类，逻辑上真的可以自洽吗？**



**第四条反直觉**：真正的AI能力有使用门槛，有的用户随便试试两款模型，认为不符合自己的预期，就以此断定AI的能力不行。

有个争议最多的问题：AI是否能接管屎山代码？

从自己的工作实践来说，AI当然可以接管复杂的工程，但依赖更复杂的提示词管理，需要更明确的约束规范，初期的慢节奏考验耐心。

要花更多的时间，把屎山需求跟AI说明白。

可以围绕自己的专业，或感兴趣的方向，用一段时间最顶级的模型，再判断AI在该领域的水平，模型的能力看似接近，但在复杂工程和细节上，根本不是相同的级别。



**第五条反直觉**：互联网企业的员工，并不可能都被AI取代，寒冬早于人工智能爆发前，相信不少人还记得那句：把寒气传递给每一个人。

**趋势向下的过程，还被AI不遗余力的推一把。**

互联网企业实践AI普遍较早，像初期的写文档和客服，中期的全栈开发写代码，以及当下AI重构工作流程，实践场景极其丰富，但是很少会在社媒发声。

拥有业务资源借AI增效，并不炒作流量的红利。



**最后回到常规的视角：该如何看待AI热点？**

互联网企业的很多岗位，每天都在频繁使用AI产品，是否能做到替代人和增效，自己心里打的是个问号，AI并不直接给业务创造需求。

有个很简单的规律：行业和业务处在上升期，企业会招兵买马抢市场。

所以单看社媒的信息奇观，人工智能行业有虚火的成份，但也在加速推进AI渗透的场景，真正有需求的领域，在悄无声息的变化。

**至于未来会如何，凑近点围观更清楚，离远点可能更清静。**
