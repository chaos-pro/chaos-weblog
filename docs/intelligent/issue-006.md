# AI引发的效率黑洞



**AI不断提高效率，成本和价格持续降低？**



**1**



2026年春节过后，互联网上的消息：一切都来的有迹可循，并且还大张旗鼓。

人工智能爆火不过三年，但是每一个现象级热点，都能对市场和认知产生剧烈的影响，把关注者带入效率的黑洞中。

**去年到现在，历历在目的事件：**

DeepSeek火遍蓝星，让很多人惊叹的是：低成本训练的语言模型，原来也能做到灵动和创意感。

VibeCoding的普及，如果说2025年之前，AI编程需要专业开发人员操持，那么2025年之后，自然语言写代码做产品，已经成为了基本共识。

Gemini模型的突围，在2025下半年，凭借出色的绘图和生态，谷歌的AI产品全面爆发，成为流量圈的热点。

**Claude的口碑越来越好，强到把软件市场吓一大跳。**

在AI领域兜一圈才发现，好用能干活的还得看Claude模型，擅长写作和编程，是普通人可以低成本尝试的两大杠杆。

**以为春节能消停几天，没想到AI产品也过年。**

OpenClaw智能体愈演愈烈，Seedance视频生成模型成功出圈，现在全网都等DeepSeek发新模型，希望能有惊喜出现。

**用户的普遍心理：好用的产品，买谁的不是花钱？**



**2**



**AI给普通人的机会，最明显的莫过于自媒体，堪称给社媒续了一波命。**

春节前在用AI编程工具，把产品的需求描述清楚，用Claude最先进的Opus编程模型，可以高效高质量的完成开发。

有不少网友认为，AI无法接管开发多年的项目。

虽然说法上没毛病，不过大部分产品，都很难走到那个阶段，最低成本的验证和试错，发现正确的方向再投入，这才是市场的一贯选择。

**VibeCoding产品本地预览，录屏发在社媒主页。**

如果被社媒的算法选中，引起一波讨论的热度，就顺手把产品发布上线，可以同时积累，自媒体和产品的用户，算得上成本极低的折腾。

**不管文章或音频视频，内容脚本是社媒传播的基础。**

语言又是大模型的核心能力，信息输入的理解和输出的组织，很能展现模型训练的背后功底，能做出和能做好，完全不在一条水平线。

**以写一篇文章来说，很多环节都可以被AI代替。**

相同内容的搜集整理，围绕主题的结构完善，文章的标题和封面设计，文本主体的润色和扩展，还可以一键转成音频和视频。

除了内容的主题，每一步都可以用AI协助。

不过问题是自媒体内容，本质是吸引流量和互动，如果全流程使用AI主导，千篇一律的感觉容易被算法识别。

**在自己的社媒账号中，其中一个手写内容，另一个给主题和框架AI写。**

比较闹心的是：手写的内容流量一般，AI写的内容偶尔爆一下；更闹心的问题是：人工智能的内容有基础流量。

非AI话题的内容，浏览量经常在10个左右。



**3**



从客观现象和规律说，AI对很多技能的替代，已经不需要质疑，专业的人在AI加持下，可以提升工作效率，成为招聘的主流方向。

**年初刷屏的一篇文章：《2028全球智能危机》。**

其中有一个假设的逻辑：AI持续提高能力和效率，对人工的替代越来越广泛，但是它的消费需求很低，企业产出的流动和收入，就会逐渐失去平衡。

此处有个循环的效率黑洞：

AI技术的迭代更新，企业会选择裁员应对，引入更多的AI工具链，照此发展下去人该怎么办？

人工智能的天花板看不见，带来的增量空间不明确，但是效率的黑洞就摆在那里，也做不到选择性忽视。

**让很多个体和企业，处在好奇和忐忑之中。**

为避免盲目的恐惧和焦虑，年初购买两款模型的会员，主要用来写内容和做产品，每天都会用到限额的程度，客观的说确实强的离谱。

这样迫使自己，去面对一个现实拷问：

到底该做点什么，才能避免被AI快速压缩生存空间。

人工智能像没有刹车的列车，不管个人和时代在不在乎，都会开往那个注定的方向，也算不上什么新鲜事。

**普通人在技术变革中，要么靠近要么彻底远离，这可能是不焦躁的唯一解法。**
