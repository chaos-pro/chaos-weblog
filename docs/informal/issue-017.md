# 互联网流量焦虑的生意



**每代互联网玩家，都有各自的套牢方式。**



**1**



最近读到一句闹心文案：说上辈人经历改革开放，虽然抓不到什么大机会，但至少没被割过韭菜，借情绪焦虑贩卖鸡汤。

**虽然没调侃这一辈的我们，不过心态还是被精准扎一刀。**

互联网从短视频开始，注意力流量被算法带到顶峰，推荐机制让内容找到用户，叠加直播的实时效果，让流量和生意的路径轻松连接。

移动互联网进程中：注意力是流量的根本。

虽然悲欢不相同，但是善变出奇一致，社媒风向总是不停刷新，平台的内容类型不断扩展，用户的习惯也在来回横跳，视频和直播以及图文，很难说清到底喜欢什么。

**从步入存量内卷开始，社交媒体的使用时长，已经在用户生理极限上蹦迪。**

越来越多的人觉得内容无趣，注意力开始辗转腾挪，或从网络回归现实，或转向文字阅读和听播客，导致商家获客成本不断提高，进入单价和成本的内卷节奏。

2023年人工智能横空出场，彻底重构流量的形态。

搜索和超级应用的入口，快速的向大模型迁移，ChatGPT和DeepSeek的用户增速，可以看出AI对注意力的吸引，经历近三年的话题热议，人工智能也彻底融入工作和生活。

**总能在公交地铁和电梯里，看见有人正在和AI对话。**

至于经常聊什么，不同模型自然各不相同，可以确定的结论是：注意力正被AI入口不断抢占，流量去哪里生意就会跟到哪里。



**2**



**互联网过去十多年：自媒体算是现象级热点。**

经过多年的狂飙，赛道彻底人满为患，对很多商家和机构来说，早已习惯付费流带货模式，自然流量被不断挤压，偶尔一条内容被算法推荐，也被严格控制在某个区间内。

社媒平台十分清楚，不能彻底遏制自然流，会影响内容的数量和质量。

即便某些博主天赋异禀，能把账号做出稳定的增速，在变现上也是举步维艰，所以内容停更或断更，选择重新回归职场，也是曾经火过的话题。

**离职能成为流量，入职也未尝不可，这就叫网感在线。**

当全网注意力向AI迁移，等于动摇社媒的根基。

用户和大模型对话，通常是明确的意图推动，讨论问题并寻求解决方案，在基数庞大的AI用户群中，画设计图写代码的需求是少数，事实上等任务执行的间隙，也会问AI各种非专业的问题。

**用户对于模型的回答：信任度越来越高。**

内容里有没有广告植入，暂时还没有统一的说法，最近两年兴起的GEO优化，可以影响AI生成的内容，在互联网广告营销模式中，已经不算什么新鲜事。

**长期的流量效果确定，但是商业结果很难衡量。**

当用户需要模型做推荐时，GEO优化过的商家和产品，在回复结果中排名更高，不过用户是否会采纳推荐，目前还没有可跟踪的机制，因为交易的流程并不在模型里。



**3**



作为新兴的付费流渠道，大部分客户虽然兴趣高，但还是普遍持观望态度。

**拿目前所在的公司说，提供模型GEO优化服务，连接权威的内容渠道，具备投放平台的代理资质，拥有专业的运营销售团队，即便价格已经压得很低，但产品的销量总是上不去。**

用户的注意力转向意图，流量分配的规则就会改变。

商家也有焦虑情绪，最先吃到的是不是螃蟹，只有尝过口感才知道，通常来说新渠道和模式，只有窗口期的成本最低，当商业路径被验证可行性，极短的时间后会人满为患。

**当然所谓的AI营销模式，只是付费流量的新手段。**

客户的真实反馈：愿意花时间详细的了解，虽然成本远低于社媒投流，但碍于效果慢和不确定性，仍会选择当前的投放模式，大环境不支持太多的试错成本。

AI大模型和智能体，正在改变过去的流量模式。

互联网过去的商业逻辑，也会随着人工智能进行产业升级，到底AI原住民和企业更适应，还是传统的过来者更具竞争力，要在转型的过程中边走边看。

**人工智能狂飙的三年时间，AI对生产力替代已成确定趋势，Token对市场的影响还要再看看。**
