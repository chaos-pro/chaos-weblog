# 互联网的热点公式



最近几个月，互联网的热点一个接一个，比如食品话题，网络舆论，营销和公关等等。

虽然事件的主体和性质有区别，相关的当事人也不一样，但从公式里看，好像又没什么变化，如同**相似的剧本，在反复的换人重演。**

互联网是一个巨大的流量池，在热点事件中，很容易聚集大量的关注和讨论，参与方都有自己的叙事逻辑，就算沉默不回应，也是一种态度表达。

**事件的客观真相，未必是关注的焦点。**

但对于热点的本身来说，最直接的涉事方，都会极力寻找自洽的逻辑，有理有据的表达，未必是双方真正的意图，叙事带来的利弊才是根本目的。

站在舆论高点的一方，如果是主动方，通常会更加积极的发声，如果是被动方，一般会选择较少的回应。

站在舆论下风口的一方，普遍是被动的参与，选择正面对线的不多见，更多是想息事宁人，实在心虚的话，不从正面回应也算一个态度。

舆论场里，当然也少不了自由发言，也就是自媒体。

这几天看的剧里，有一句台词：真相有价值。

那么真相对谁更有价值，才是热点事件中的叙事关键，不同层次的舆论，会从站位和影响上考虑，选择不同的切入角度，从而刷新网络对真相的认知。

**最精辟的手法：表达事实的一部分。**

从观点上不出错，不过是对的不够全面，舆论对真相的影响，是一叶知秋，还是一叶障目，既要看表达方的驱动力，也要看阅读方的理解力。

互联网的热点事件，客观真实的全貌，需要从各种只言片语中拼凑。

主动方要举重若轻，被动方会避重就轻，自由的一方，会分层次的举重或者拎轻，多方的言论推动热点事情的发展，看似无序实则有序。

事后想一想，热搜千篇一律，有趣的观点其实也一样。
