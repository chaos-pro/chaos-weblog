# 打工人如何学点东西



每到年底的时候，习惯重新整理一下电脑，找找哪些文件要清空，哪些资料要上传云端备份。

还有少部分，短暂的保留，放临时文件夹里。

其中删除最多的文件，依旧是零散的知识文档，整一年积累下来，参考资料似乎堆了不少。

**但是没有一个文档，可以完整的读完。**

打工人应该都有这个问题：电脑里学习资料一大把，云盘上存放的文件一大堆，视频和文档以及工具应有尽有，大部分资料都基础又全面。

**收藏从未停止，行动从未开始。**

打工人的工作时长和休息时间，几乎不可能把资料从头看到尾，普遍只能看个开头了解一下，或者把教程当字典查阅，需要什么看什么。

从开始工作之后，没有细致全面的学过知识。

**普遍都是从项目中，要解决的问题里，倒推需要恶补的知识点，如果项目周期长或问题复杂，相应的知识就会学的广泛和深入。**

这和学生时期完全相反，在校读书从零开始，什么时候用上完全不清楚。

打工人在职场主动或被动，接收和学习各种知识，对工作和自身来说，并不算一件特别友好的事情，现学现卖需要更多的时间和心思。

**不能游刃有余，手忙脚乱还容易出错。**

不过学习也算工作中的乐趣吧，从复杂的项目和问题中提升自己，可以更自信的面对未知情况，能力和收入总得收获一个。

最近两年大模型崛起，学习技能的方式再次进化。

不管是在学校还是在职场，以前是阅读现成的文档或教学视频，学习流程和时间周期较长，现在更多是大模型对话提问，可以快速的提升效率。

**各类大模型助手，全天实时回答任何问题。**

节省找资料的时间，免去文档识别的功夫，只要告诉AI自己的情况，让它实时生成学习路线，并且把需要阅读的资料整理好，过程中不懂的问题，还能够进行实时解答。

或者由模型生成路线中的教学内容，甚至设计具体的实践方案。

比如对话中这样输入：

产品新手小白，想用两天时间入门，设计一个简单的路线，可以快速理清学习脉络。

模型的回答非常务实：

第一天看基础文档，第二天做个入门案例，最后总结和搭建完善的学习框架。

值得一提的是，学习没有捷径可走，任何知识都需要时间和实践，才能够熟练的掌握，互联网常说人人都是产品经理，不过张小龙和微信只有一个。

**人人都是自媒体，这句话还算清醒。**

学习是知识输入的过程，除了用在工作中解决问题，还可以制作成笔记输出，把实践过程和知识要点写清楚，就是很有诚意的内容，自己加深理解还帮助其它人，网感好还能收获关注。

**流量做大了叫博主，做不大依旧是网民。**
