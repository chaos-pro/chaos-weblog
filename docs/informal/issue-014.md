# 2016已经是十年前



**初入社会的梦想，成了握在手里的把柄！**



**1**



每到岁末年初，写总结规划的时候，就有两句名言冒出来：

计划赶不上变化，所以计划完不成；唯一不变的就是变化，所以计划要改变。

于是总结可以这样写：

**过去的目标完不成，倒欠自己的目标，选择道个歉翻篇。**

对于规划可以这样说：

**新年新计划，转过身来努力面前，去年还能用的目标，悄悄的复制到计划清单中。**

总是在设想的时候，习惯雄心壮志；容易在执行的时候，鼓起一天干劲，再而衰三而竭。

职场的早期阶段，在所谓的厂里搬砖。

那会和现在不一样：同事间还能看到朋友圈动态，各种生活和工作晒到发黑，印象最深刻的是跨年那几天。

有不少人捧着笔记本，蹲在咖啡店写总结规划。

心满意足地完成后，拍几张岁月静好的画面，然后告诉朋友圈的亲友们，自己的生活和工作都挺好。



**2**



离开学校入社会的第一年，是多数年轻人最有心气的阶段。

人生走进一个新阶段，可以像大人一样赚钱，还能疯狂的积累各种经验，关键是没挨过社会的毒打，总想着大干一场。

**两脚踩在地上，双眼又仰望星空。**

大学里的几个损友，在群里聊自己的梦想，被截图保存到云相册，想着实现后贴出来祝贺，没想到成了握在手里的把柄。

年轻那会做的梦，老实说没干成几个。

2016年的互联网大厂，公司的每个项目组都超过二十人。

在一个大的团队中，有几个工作十年以上，有一批工作五年左右，还有小部分初入职场的实习生，虽然人员变动进进出出，但是整体结构很稳定。

**不同阶段的打工人，忙着五花八门的事情，又都有各自的计划。**

十年的规划方向，摸鱼时间顺手倒腾点私事；五年是干活的主力军，整天盯着好公司和位置，谋划着再进一步；实习生干杂活，满脑子想着快点成长，不然做人做事没底气。

**当时的负责人常说：求人不如求己。**

现在想来也是有趣，抛开工作能力不谈，从干活的态度上说，必然是年轻的实习生最端正。

初代同事之间，容易混成朋友，在一起吃饭的时候，偶尔聊几句未来想法。

实习生忐忑中带几分向往，五年的同事谨慎中略带一丝迷茫，十年的同事指点中带一丝回味和欣赏。

**不同年龄段的人群，按照经历分配人生态度。**

2026年再回过头瞥一眼，过往历历在目，当时的那点不理解，心底里早已有了答案。



**3**



初入社会到五年和十年，快的就像弹指一挥间。

**实习期的计划**：顺着职场向上走，挣到足够多的存款，积累实力之后创业，绝对没有躺平的念头。

切换城市和公司后，不稳定和加班成常态。

**工作五年左右**：想找个安逸点的公司，清醒的面对现实压力，未来是创业还是躺平，在想法上开始动摇。

互联网寒气蔓延，保暖和内卷又成难题。

**职场十年过后**：上班就是创业，休息就选择躺平，总之不想再为难自己。

**谋生是一条主线，谋生活是另一条主线。**

两条线相互交织拉扯，让生活变得千头万绪，后来分不清东西南北，直到人工智能强势登场，成为互联网的风向标。

**职场的规划落空很多，生活的谋划形同虚设。**

在很多人小的时候，都计划自己必须长得好看，每年春节过后，又打算靠着减肥整容一把，生活稳定的片刻，习惯靠做梦打发一下。



**4**



计划和目标成与不成，背后的影响因素很复杂，不过总结起来一句话就够：

**自己做不到，客观主观的原因都有。**

经历越是复杂，越懂得从现实角度看问题，处在社会这个大环境下，必然会被整体的趋势裹挟，企业的老板们常说顺势而为。

**行业向上的好时候，抓住机会大干一场；行业向下的寒冬中，要懂得及时保暖。**

职场的经历中，待过两家十年以上的公司。

应对行业的趋势反转十分果断，其中一家打包卖掉相关业务，另一家寒冬前完成降本增效，目前都活得好好的。

社会趋势算客观原因，应对手段是主观因素。

**个人经历：似乎不值一提。**

互联网的降本增效，房地产的爬高走低，两个最耀眼的行业和人群，该用什么样的计划，来应对趋势的起起伏伏？

**个人和公司以及行业，形成一个复杂的环境系统。**

企业每年做规划和预算，会细化到季度和月份，在日报和周报里追踪执行进度，发现问题会及时调整，但从结果上看，目标和追求基本不变。

裁员降本内卷增效，无论个体抽中哪一样，都不符合预期的规划。

稳定安逸时做的计划表，与突发的棘手状况对比，总要权衡利弊和取舍，很难按照僵硬的路线走完，需要调整的时间和空间。

**人工智能的进化速度，把割裂和焦虑推向极致。**



**5**



今年的元旦假期，下意识刷新朋友圈动态：

只有一位朋友发自己的目标，雄心壮志的说到：新年一定要新高度。这个目标在当下的含金量，不得不令人羡慕。

**其它人估计也会写，不过动态仅必要的人可见。**

看过几篇计划和变化的分析长文，主流的观点和逻辑是：先具备实现计划的能力，再通过执行完成自身的变化。

**简单的逻辑，复杂的文笔包装。**

春节见了好多亲友，有的开店做生意，有的在县城安稳打工，有的在城市不回去，表情和眼神能看到真实的近况。

计划里的目标，不想走的老路，都很难轻易做到。

**生活的一粒沙，不知不觉地落下来，有的落在肩膀上，有的落在脚底下。**





2026\.2\.27
