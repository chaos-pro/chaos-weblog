# 问薪：干一行恨一行?



如果让当代的打工人，用一句话形容职业现状，大部分应该都会来一句：干一行恨一行，行行破大防。

初入职场不知道，虽然能听到资深老员工的唠叨。

打磨久了才知道，但是已经不情不愿的成为老员工。

特别是工作两三年以后，心态很难保持平衡，心底也说不清楚，到底恨的是行业，还是公司的岗位。或是挣脱不开的自己。

**总觉得亏点什么，付出那样多，回报不够多。**

从进社会开始，就在互联网行业，以实际的经历来说，相当一部分人喜欢这个行业。

**但都不喜欢：自己的岗位。**

在互联网的公司里，身处明亮的办公室，捧着高配的笔记本，说着连同事都似懂非懂的黑话，拿着一份不算低的薪水。

不得不承认，这种状态容易上瘾。

前提是你能够：选择性忘记付出。

比如习惯加班，习惯随时收到消息，习惯持续学习，习惯降本增效，习惯今天解决问题，习惯上午内卷下午卷铺盖。

**你可以同时拥有：较高的薪水和特别高的付出。**

不仅如此，还得担心被同事取代。

在互联网行业这么多年，彻底转行的很少见，但是转岗的却比比皆是，技术岗位想转产品，产品岗位想转管理，管理岗位想转老板。

人工智能上位后，一个能卷的都没有。

**以前只说人人都是产品经理，现在高呼一个人就是公司。**

在时代的趋势面前，个人的经历不值一提，在技术变革的加持下，追求高度自动化和智能化，这是很多人甩不开的一粒沙。

互联网接触信息极快，几乎每天都要面对AI的灵魂拷问。

人工智能爆火前，只会嘴上说说三十五岁危机，现在每天一睁眼，就得看看自己，又被谁家的模型取代了，等到真被取代的那一天：

是怪自己不够努力？还是吐槽取代自己的同事？又或是怨技术发展太快？

似乎都合情合理，只是自己被困在原地，无奈的东张西望。

以前自己反复掉进迷茫中，焦虑怎么摆脱现状，直至现在也无法坦然应对，不过在各种毒打中，被迫想明白一件事情：

**反正躺不平卷不赢，就只好承认客观现实。**

现状的自己是啥样就是啥样，现实的环境是什么就是什么，尽量保持自洽的心态。

认清现实不是自暴自弃，而是能改变的就改变，不能改变的就假装接受，状态好的时候就卷一会，状态差的时候就躺一会。

以前刷到过一条内容，到现在都记忆深刻：

一个网友发帖说，处在一个内卷严重的职场环境，感觉自己身心俱疲，有很多人留言：告诉这位网友，如何利用摸鱼的时间提升自己，然后顺利的换家新公司。

**但是最扎眼的一条评论说：身心俱疲不是该休息吗？**

以前的自己也会觉得，该卷起来再跳槽，后来认为休息也合理，现在感觉做个自洽的选择就好，谁也不能确定，换个方向走几步，就能柳暗花明。

**每一个新年的开始，依旧是过去的生活在继续。**

当然该吐槽，还是要吐槽，人工智能都打算取代我了，还不能抱怨它几句吗？





2026\.1\.21
