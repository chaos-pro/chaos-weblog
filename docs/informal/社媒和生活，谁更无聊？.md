# 社媒和生活，谁更无聊？



当自己无聊的时候，频繁的看社交媒体，几乎成了无意识的动作，特别是运营自媒体账号，总是不经意的关注动态。

**从最初单纯的猎奇内容，到现在自然而然的习惯。**

社媒上的信息流，占据大部分生活的空隙，心里也清楚没什么有趣的，还是在不同平台循环横跳，每个应用随便点一点，觉得无聊就换下一个，躺着不动知道其它的人和事。

等时间过去后，会觉得更枯燥，只能接着刷社媒对抗无聊。

**重复的内容和话题，不约而同地出现在推荐里。**

自己究竟更关注什么，可能心里未必清楚，但是算法可以分析的明白，看到的内容自然大差不差，就算意识到是个问题，但是惯性很难轻易改变。

**怎么会养成这个习惯？因为生活似乎比玩手机无聊。**

如果不是能力有限，谁乐意只从网络了解世界，刷一百次远方风景，不如自己漂洋过海看一次。

与另一个有趣的话题类似：为什么很多打工人，宁愿在公司做卷饼，也不愿意直接离职？自然是离职的压力比内卷更大。

**泛滥的社媒信息，会影响对生活的感觉。**

**过度关注多方面消息，忘记看看真实的自己。**

自己的处境如何，算法懂得量身定制，要么寻找感同身受，告诉你众生都一样，要么推送更多娱乐信息，开心一天算一天，生活的时间空隙，就是这样被占据和缩短。

**无聊不是病，打发无聊却像个患者。**

如果希望生活更充实，是不是该卸载社媒？你我他都知道不可能，也没有这个必要，什么样的时代背景，就过什么样的生活。

**人嘛总归被什么套牢，不是生活就是谋生活。**

在个人的脑回路上，不轻易论断对和错，面对不合理的情况，合理的办法是反思，然后不断提醒自己要注意，想办法让习惯产生好的影响。

在社交媒体投入注意力，可以接收信息和解决问题，存在实打实的帮助和收益，只是时间成本高的太多，付出和回报的差距很大。

**很多网民意识到问题，努力的向博主转型。**

以自媒体输出作为驱动力，从内容的主题出发搜索社媒，让信息输入形成知识，让信息输出产生影响，从两个角度作平衡，降低在社媒里损失。

**长此以往，这也会成为习惯。**

**避免单纯的精神内耗，强迫自己转移注意力。**

很多年保持的习惯，如果能够轻易的改变，那么新养成的行为，未必没有丝毫的问题，事物的两面性，只会转动不会消失。

**人的猎奇心和胜负欲，总是会成为被拿捏的弱点。**
