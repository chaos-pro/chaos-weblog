# 自媒体内容如何找角度？



最近这两年，洋洋洒洒的写过好多内容，在练笔的过程中，科普类的内容主线，重在对过程和客观事实描述清楚，但是观点表达，需要反复斟酌切入角度。

**发布到社交媒体，最关键的就是标题和封面。**

至于内容本身，使用什么文字风格，单纯是表达的技巧而已，这些可以生搬硬套模仿出来，所以如何拿捏文字可以练出来，但对于事物的理解观察和想象，这就很考验个人的天赋。

**观察的全面，理解的透彻，才容易找到独特的切入点。**

分析过很多头部自媒体账号，制作一篇优质长文最多可能需要几个月，内容中的时间线可能横跨好多年，叙事风格草蛇灰线，然后收尾处寥寥数笔点睛。

**虽然出发点模糊，但字里行间的方向非常明确。**

另外三种比较主流的角度：支持，反对，端水大师。

对于算法推荐而言，坚定的观点更容易出圈，比如当年的萝卜快跑，又如今年的预制菜风波，不同的观点在一起打的热火朝天，形成巨大的流量效应，最后端水的出来刷地板收场。

把内容写的绘声绘色，还需要一些想象力。

明明是一个小土包，用蚂蚁的仰视切入就是高山，用飞鸟的俯视切入就是平地，缺乏想象力就只能见山是山，发挥想象才可能见山不是山。

观察理解和想象，是优质输出的基本条件。

在此基础上去编排内容，就可以把事情和人物描述的完整立体，故事的前因后果，当下以及后续的可能走向，人物出场的顺序，以什么样的心态和行为，想要在事件中达到什么目的，最后用文字摆出来就行了。

**厉害的写手，懂得斟酌文字的尺度，在千头万绪中，似是而非不沾因果。**

理解内容如何制作，再看纷纷扰扰的信息流，普遍也就没那么有趣了。
