# 岗位减少，职责增加？



**现实自带几分焦虑，但是无意于声张。**



**1**



2016年进企业开始实习，那会互联网公司也卷，但没有持续的心累和焦虑感，降本增效也不是主节奏。

**十几个人一组，每月迭代几个需求，各个岗位都谨慎负责。**

在产品研发团队中，从项目到产品到设计，从测试到前后端开发到运维，还有数据库专家和架构师，不仅岗位角色搭配完整，协作周期也会合理评估，当然考核机制同样严格。

**人和时间充足活还干不好，挨批评自然也无话可说。**

常规大版本按月执行，每个人的任务只有小部分，完成后都是在跟进流程，有工作经验的老员工，为减轻职场被关注的压力，甚至主动揽活避免周报不好编。

当企业发展到一定阶段，业务的上下游流程太长，参与的人越多越复杂。

随着信息化到数字化迭代，组织协作的效率越来越高，互联网趋势反转走下坡路，再被AI强势的推上一把，打工人的职场难度陡然增加。

**最直观的魔幻现象：虽然岗位减少，但职责却不断增加。**



**2**



互联网从存量竞争开始，在寒冬里追求降本增效，团队岗位配置开始缩减，外包介入的流程不断增加。

**最初影响的岗位：测试和运维及项目经理。**

测试可以保证产品的质量，开始转向产品和开发自测，运维交给程序员接手，项目基本由资深人员代劳，等初期通过市场验证，再看情况慢慢的补人，不过落差感是生活常态。

都说互联网公司看三年，这几年普遍看三到六个月。

人工智能从登场以来，替代是最热门的话题标题，前两年贩卖焦虑无处不在，但当时AI不具备替代能力，去年几款模型能力被认可。

**编程领域更是大放异彩，依赖审美的设计也惨遭冲击。**

从2025下半年开始，Claude模型的编程，Gemini模型的绘图，GPT模型的通用性，Seedance模型的视频生成，AI对垂直领域的效率提升，被市场和打工人广泛认可。

时间到2026年的当下，很多影响已经非常明显。

AI从垂直领域伸向组织协作，围绕核心的模型和AI产品，持续打造和丰富插件市场，让AI的能力重构工作流程，纯粹的人和人对接开始动摇。

没有AI助手之前，打工人尚且焦虑职场危机，在AI闯进工作流之后，更是毫无稳定性可言。

**目前还算稳定的岗位：产品经理和全栈开发。**

产品要和多方对接业务需求，全栈开发要解决所有技术问题，指挥AI执行简单重复的任务，在Codex产品中甚至可以融合管理，对岗位的能力要求更加苛刻。

今年三四月份的招聘，从数据和直观感觉说，需求量似乎有回暖迹象，自然是受到AI和Agent影响。

**但求职者普遍有个疑问：企业到底想找什么样的人？**

别说求职者很难理解，公司内部的HR也未必清楚。

**首先必须具备专业经验，其次具备一定的技能广度，最好还是AI时代的原住民，年龄还必须符合红线要求，如果有大厂经验自然最好。**

把要求翻译成白话：花最少的钱招最合适的人，实力不一定需要最强的，但入职就能干活是必须的。

**社媒上有很多网友吐槽，今年求职和招聘都很难。**

按上述要求搭配的部门岗位，非常契合公司的内卷姿势，只要业务和产品和技术，逐步形成稳定的工作流程，每个岗位的职责都独挡多面。

时长和任务没有增加，不过脑腐的感觉非常强烈。

AI进入工作流以后，接收和处理的信息密度高，AI执行效率也会反向驱动，更抽象的是产品开发的分工，也在潜移默化中互相融合。

当AI的能力足够跟得上，产品可以适当编程，全栈也可以分析需求。

**既然人人都是产品经理，那人人都是程序员也未尝不可。**

如果认为该现象不可理喻，那去年火到现在的一人公司，也就是所谓的超级个体，更难代入AI的视角去欣赏，但热潮和趋势就客观存在。



**3**



**形成趋势的任何现象，都有底层的支撑逻辑，也就是常说的存在即合理。**

互联网增量到存量反转，降本增效几乎不可避免，头部产品的通吃效应愈发明显，也在挤压其它公司的生存空间，压力必然会传导在打工人头上。

更少的投入做更多的事，在主打性价比的基础上，企业和用户对产品质量，也默契般的产生一些容忍度。

行业趋势向下的阶段，公司和个人都有压力。

被迫聚焦在关键维度和因素，不得不忽略很多边缘问题，生存下去才能等到趋势反转，人工智能的发展和应用，正好给了市场新路径，用来顶替企业非必须的岗位，职责就留给在职的人员。

**当然也提供更好的口径：不是业务收缩导致裁员，是AI新技术的广泛应用。**
