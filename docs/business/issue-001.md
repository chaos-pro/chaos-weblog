# 大奖就是百抽不中



**奖池中的大奖，可以买走。**



**1**



在偏重运营的产品中，通常都会涉及以下这么几个功能：抽奖体系，营销推广，日常活动等，以此来增进用户在产品内的停留时长，进而促进核心业务的转化。

从实际效果看，这些手段确实有效，可以提升用户活跃度，提升产品的商品曝光次数，但是要注意避免套娃，避免运营策略的过度复杂，用户不想看或者看了也不懂的有大把。

**比如那谁和那谁，策略再复杂，都玩不过那谁的仅退款。**

下面来聊一聊抽奖体系的设计策略，从实践过程来说，抽奖的流程并不复杂，核心的因素就那么几个：奖池配置和摇奖机会。在抽奖功能调研阶段，体验过几款主流消费小程序中的摇奖页，但是体验结果都比较差，普遍是中奖的奖项没什么可用的场景，或者谢谢参与的权重太高。

在配置奖池时，至少要考虑到这几点：大奖有足够吸引力，即使没概率；中奖要丰富且实用；小奖最好与抽奖成本不相上下。

**避免踏空，下次一定。**



**2**



在奖池的品类配置中，通常分为实物和虚拟两种，当然还有不受用户待见的谢谢参与；两种品类的配置比例通常旗鼓相当，只是在不同的摇奖方式里中奖的权重有差异。

在实物品类中，参考产品的实际交易场景，可能有个别热门的稀缺商品，也有个别冷门的滞销商品，多数都只是普通的在售商品。

在虚拟品类中，通常有各种优惠券、代金券、红包券、满减券等，其本质还是为了促进交易转化。

**商品降价，和发满减券的促销手段有本质差异。**

在奖品库的配置中，还要考虑库存的问题，合理的分配奖品库存的占用量，避免库存不足或者过度占用的问题，根据抽奖记录的统计，动态调整库存或更换奖池配置。

对于实物商品来说，中奖之后还要有相应的发货流程，及时将奖品发送给用户。

**奖池中，难逃抽大奖抽不中的定律。**

毕竟那只是给奖池充门面的，很大概率不会被直接抽走，只有可能在特定时间特定人群中，才能获取真正抽中的概率，仅是概率。

**就像直播间的福袋一样：中大奖的到底是家人们，还是家人们的账号？**



**3**



在完成奖品库的管理后，则可以从奖品库选择奖品，创建具体的奖池版本；还可以根据产品的端口或者设备类型以及用户群体的分布等，创建不同的奖池类型，直观上的差异可能只是奖池的奖品和获奖权重。

**搭建奖池时，涉及三个核心维度：选品，权重，抽奖机会。**

首先考虑的选品，根据产品运营的实际情况，对实物和虚拟两种奖品进行组合配置，或者给一些滞销商品配置单品优惠券，促进该商品的曝光和销售转化。

其次就是不同奖品的权重，权重简单来说就是抽中的概率，通常需要对不同的抽奖方式进行单独配置，比如免费和下单所得积分的抽奖机会，其不同奖品的摇中概率是不一样的，目的是为了控制抽奖活动的运营成本。

最后抽奖机会的发放，可能是每日的免费抽奖，通常摇到的都是下次一定；积分或者产品的虚拟币抽奖，大概率能得到小面额的优惠券；完成指定任务或者参与某些活动，可能获得实物商品。

**摇奖最神奇的地方则在于概率的算法，占星术都未必解释的明白。**

**在常识里，中奖的概率符合权重随机算法。**

权重高的奖品抽中的概率就高，这个常识并没有错，然而成熟的产品中有大量的用户行为数据，所以可以理解用户群的千人千面，通过简单的标签就可以实现分层管理，那么摇奖概率就可以做到因人而异。

**简单说：SSSVIP用户在特定时间下摇到大奖的概率极高。**

在用户分层体系下，新人用户，普通用户，老用户以及可能流失的静默用户，氪金的VIP玩家，在同一个摇奖流程中可以做到不同奖品的权重偏移。



**4**



在完成奖品库和奖池设置后，就到了用户的抽奖环节。

**站在用户角度看：**

如何获取抽奖机会和能摇中什么奖品，才是参与活动的阻力和动力所在，过于复杂的规则或者毫无实用性的奖池，都很难达到产品的预期效果；抽奖机会通常来自产品的交易链路和运营活动中，比如下单达到多少笔数或金额，获得多少相应的积分，以及浏览广告或者分享产品主页等。

如果抽中虚拟商品，则会由系统直接发放到账户中；如果抽中实物，则需要用户确认收货地址后，进入发货流程。

**站在系统层面看：**

整个抽奖的管理链路是偏复杂的，涉及用户抽奖机制的核验，奖池奖品的核验，基于特定规则下的抽奖概率偏移，抽奖结果的记录和发放以及核销流程；除了用户感知的抽奖交互流程，还需要完成数据层面的记录和分析。

**产品多数功能的优化依据都来自数据指标的分析。**

要分析抽奖模块是否达到预期效果，可以参考几个核心指标：抽奖入口的曝光量，抽奖页面的访问量，抽奖页面的停留时长和点击率，中奖后奖品的领取核销等；这样可以比较清晰的定位问题所在，并快速的做出相应的调整。



**5**



最后聊一聊数据体系的平衡原理，本质是运营成本的精细控制，尤其是抽奖体系中，很多成本都是隐性的，并不像交易流程那样，各个环节的差价都比较明显。

**以积分抽奖为例：**

通常积分的获取是由用户购买行为转换得来的，假设金额满100可得1个积分，那么就需要衡量这个积分的转换价值即相当于多少金额，在积分使用的场景中，则使用一个相对合理的积分估值去判断可兑换到的价值。

假设10个积分约等于金额10，参与一次抽奖核销掉的积分，可能获得的奖品价值理论上会小于10金额，从数据层面核算，才能更好的评估运营成本，做出合理的设计。

**体验过几款产品的抽奖功能，在连续摇了N把之后，奖品没有抽到，还把自己的积分清仓了。**
